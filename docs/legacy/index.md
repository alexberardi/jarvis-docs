# Legacy: the old Docker install

Before Jarvis Automation, Jarvis ran as a set of Docker microservices installed by `jarvis-admin`. That install is retired for new users: it no longer installs out of the box (MinIO is gone).

The pages in this section are kept, frozen, for anyone still running it. They are not updated and search engines are asked not to index them. Each page's old address still works and brings you here.

- New install: [Install Jarvis Automation](../install/index.md).
- Moving an existing install: [Migrating from the old install](../install/migrating-from-docker.md).
