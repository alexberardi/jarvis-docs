# Migrating from the old install

The old Docker/microservice install is retired for new users: it no longer installs out of the box (MinIO is gone). An existing install keeps running, and its pages are kept, frozen, under [Legacy](../legacy/index.md). This page will cover moving your households, accounts, devices and routines to Jarvis Automation.

Jarvis Automation is a **pre-release** (release candidate rc18). Builds are on the [releases page](https://github.com/alexberardi/jarvis-server/releases); each one is marked *Pre-release*, so open the newest and look under **Assets**.

This page is a stub; the full guide is on its way.
