# Server on Linux

Download `jarvis-automation-server_<version>_amd64.deb` (or `_arm64.deb`) from the newest release and install it with `sudo apt install ./jarvis-automation-server_<version>_amd64.deb`. Then open the [setup wizard](setup-wizard.md).

Jarvis Automation is a **pre-release** (release candidate rc18). Builds are on the [releases page](https://github.com/alexberardi/jarvis-server/releases); each one is marked *Pre-release*, so open the newest and look under **Assets**.
