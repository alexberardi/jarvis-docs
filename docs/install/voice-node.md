# Voice node

A voice node is a small device with a microphone and speaker (a Raspberry Pi, for example) that listens for the wake word and talks to your server. Each release carries `install-pi.sh` for it. Until this page is written, [Node Setup](../clients/node-setup.md) describes the node.

Jarvis Automation is a **pre-release** (release candidate rc18). Builds are on the [releases page](https://github.com/alexberardi/jarvis-server/releases); each one is marked *Pre-release*, so open the newest and look under **Assets**.

This page is a stub; the full guide is on its way.
