# Advanced one-liners

Each release also carries install scripts: `install.sh` and `install.ps1` (the server), `install-agent.sh` (the desktop agent) and `install-pi.sh` (a Raspberry Pi voice node). `SHA256SUMS` and its signature `SHA256SUMS.minisig` let you check every file before you run it.

Jarvis Automation is a **pre-release** (release candidate rc18). Builds are on the [releases page](https://github.com/alexberardi/jarvis-server/releases); each one is marked *Pre-release*, so open the newest and look under **Assets**.
