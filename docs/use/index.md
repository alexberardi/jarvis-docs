# Use Jarvis

Once the server is [installed](../install/index.md) and its [setup wizard](../install/setup-wizard.md) is done, you talk to Jarvis through any of these. They all reach the same server, so they share the same commands, memories, devices and routines.

| Where | How you talk to Jarvis | Set it up |
|---|---|---|
| **A voice node** in a room | Say "Hey Jarvis", then your request; the node speaks the answer. | [Voice node](../install/voice-node.md) |
| **The mobile app** (iOS, Android) | Chat by text or voice, and manage nodes, devices, routines and Pantry packages. | [Mobile app](../install/mobile-app.md) |
| **The web app**, in a browser | Open **Chat** at `http://<host>:7710/chat` and type. Any household member can sign in. | Nothing to install |
| **The desktop agent** on your computer | Say "Hey Jarvis" on the computer, dictate, and let Jarvis open apps, links and browser tabs. | [Desktop agent](../agent/index.md) |

`<host>` is the machine the server runs on, or `localhost` on that machine.

## What to try first

- "What is 5 plus 3?"
- "Set a timer for 10 minutes."
- "Remind me to check the oven in 20 minutes."
- "Add milk to the shopping list."
- "Tell me a joke."

The [home page](../index.md#built-in-commands) lists the built-in commands. More, such as weather, news and music, come as packages from the [Pantry](../mobile/pantry.md).
