# Mobile App

The Jarvis Automation app (iOS/Android) is the main way to manage Jarvis, your voice assistant. Use it to chat with Jarvis, manage nodes, install packages, configure routines, and control smart home devices.

## Navigation

The app uses a bottom tab bar with five tabs:

| Tab | Purpose |
|-----|--------|
| **Home** | Chat interface --- text and voice input |
| **Devices** | Smart home device list and control |
| **Pantry** | Browse and install community packages |
| **Routines** | Create and manage multi-step voice routines |
| **Nodes** | Voice nodes and computers running the desktop agent |

The Home header has **Settings** (gear icon), **Inbox** (bell icon), **New conversation** (plus icon, which clears the chat) and a help icon. **Add Node** and **Add a computer** are buttons on the Nodes tab.
