# Add a computer

**Jarvis Automation Agent** connects your own computer (macOS, Windows or Linux) to your Jarvis Automation server: "Hey Jarvis" on the computer, apps, windows, dictation and your browser. Its guide is the [Agent](../agent/index.md) tab:

1. [Install the agent](../agent/index.md#install) on the computer and open it.
2. [Pair it](../agent/pairing.md): approve its code in the web app or the mobile app.
3. Set up [browser control](../agent/browser.md) and, on a Mac, the [permissions](../agent/macos-permissions.md).

## Turn on website access

The browser extension needs access to all websites before Jarvis can read or act on pages. The steps for Firefox and Chrome-family browsers are in [Browser control: Turn on website access](../agent/browser.md#turn-on-website-access).
